Le projet consiste en une analyse d’un jeu de données à partir d’une question scientifique (ou de plusieurs...) qui devra être déterminée par vos soins. A chaque jeu de données (enregistrés sous .csv) est associé un fichier dit « contenu » (enregistré en .txt ou .pdf) qui décrit le contexte du jeu de données. 

## Organisation

Vous devez vous organiser rapidement : 

    Former des groupes de 3 étudiant.e.s (il est possible de vous mélanger entre les deux groupes)
    Choisir un sujet. Pour les sujets, vous êtes libres d'aller piocher dans les jeux de données disponibles dans le dossier global (ici), ou de choisir un jeu de données qui sera commun à votre projet SIG (ici).

## Séances projet

La première séance projet aura lieu le 2/11. Préparez-vous : elle comportera une présentation « Mon projet en 180s », où vous présenterez ce que vous avez l'intention de faire. Cet exercice n'est pas noté, mais il vous permettra de réfléchir collectivement à votre travail dès le début du projet. La dernière séance vous permettra de poser vos dernières questions.

Format et contenu du rapport

Le projet doit faire 6 pages (hors scripts, à mettre en annexe). Il doit comprendre :

    une présentation des données (graphiques R ou Excel)
    une analyse complète répondant à une question posée (ou plusieurs analyses pour répondre à plusieurs questions), en suivant explicitement la méthodologie et les étapes des tests, y compris la vérification des conditions d'utilisation par d'autres tests
